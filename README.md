# otus-cpp-basics

Учебный репозиторий для самостоятельных работ по базовому курсу C++.

## Цели

- Изучить основы программирования на C++.
- Освоить работу с Git и GitHub.
- Научиться создавать коммиты, работать с ветками и сравнивать изменения.
- Хранить решения учебных заданий.

## План работы в ветке test2

1. Повторить назначение Git и GitHub.
2. Потренироваться создавать ветки и коммиты.
3. Сравнить изменения между ветками.
